# LAST TALK

卒業するその前に、聞いておきたい話がある。

青年会議所などの「卒業生を送り出す懇親会」で使う、参加型トークゲームです。
笑い → 思い出 → 仲間 → LAST MESSAGE と感情の流れに沿ってお題が出て、最後は「卒業おめでとうございます」で締めくくります。

設計の詳細・お題一覧は [docs/DESIGN.md](docs/DESIGN.md) を参照してください。

## 使い方（当日）

1. トップの **START** → 卒業生の名前と呼び名を登録（最大10名）
2. 話す卒業生を選んで **お題を引く**
3. 回答が終わったら **NEXT**。卒業生を変えるときは上部の名前をタップ
4. 流れが「仲間」まで進むと **LAST MESSAGE ›** が表示されます
5. **MESSAGE** → 最後のお題 → 全員終わると **フィナーレ**

困ったら右下の「司会メニュー」から：次のお題 / スキップ / ひとつ戻る / カテゴリー変更 / 特別カード / 盛り上がり・しっとりモード / 会場モード / LAST MESSAGE へ / 最初に戻る

### 表示のおすすめ

| 使い方 | おすすめ |
| --- | --- |
| PC をプロジェクターにつなぐ | 全画面（F キー）＋会場モード。プレゼン用リモコン（→ / PageDown）で進行可能 |
| スマホで司会しつつスクリーンに映す | スマホを画面ミラーリング（AirPlay / HDMI 変換）して投影 |
| スマホだけで回す | そのまま使用可 |

※ サーバーを使わない構成のため、「スマホ（操作）と PC（表示）を別々の端末で連動させる」機能はありません。

## スマホだけで使う（PC 不要）

`npm run standalone` で、アプリ全体を1つのファイル `standalone/last-talk.html` にまとめられます。
このファイルをリンクで開けるようにすれば、スマホだけで準備から本番まで完結します。
進行中はスマホの画面が自動で消えないようにしています（対応ブラウザのみ）。

## 開発

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # 出題ロジックのテスト
npm run build   # out/ に静的ファイルを書き出し
npm start       # out/ をローカル配信して確認
```

`out/` フォルダを Vercel / Netlify / GitHub Pages / 社内サーバー等にそのまま置けば動作します（ログイン・DB 不要）。
フォントはビルド時に同梱されるため、一度読み込めば会場の回線が不安定でも表示は崩れません。

データはブラウザの LocalStorage（`lasttalk:v1:*`）に保存されます。別の端末・別のブラウザには引き継がれないため、**当日使う端末・ブラウザで事前登録**してください。

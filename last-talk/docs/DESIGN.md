# LAST TALK 設計書

> 卒業するその前に、聞いておきたい話がある。

卒業生を送り出す懇親会で使う、15〜30分の参加型トークゲーム。
「サイコロで決める」のではなく、**司会者が NEXT を押すたびに、感情の流れに沿ったお題が1枚ずつ出る**形式。

---

## 1. アプリ全体の設計

| 項目 | 方針 |
| --- | --- |
| 体験の軸 | 笑い → 思い出 → 仲間 → 感謝（LAST MESSAGE）と、場の温度が自然に移り変わる |
| 主役 | 卒業生。画面上部に常に名前、中央にお題 |
| 操作 | 1画面1アクション。主ボタンは常に画面下中央の1つだけ |
| 司会 | 右下の目立たない「司会メニュー」に全ての例外操作を集約 |
| 準備 | 卒業生の名前を入れるだけ。お題は標準で63問（卒業生へ52・現役へ11）＋特別カード5種を内蔵 |
| 技術 | Next.js（App Router / 静的書き出し）＋ TypeScript ＋ Tailwind CSS v4 ＋ Framer Motion |
| 保存 | LocalStorage のみ。ログイン・DB・サーバー不要 |
| 配信 | `next build` で `out/` に静的ファイルを書き出し、任意の静的ホスティングで動作 |

### 感情の流れ（自動進行）

```
 笑い (LAUGHTER) ─▶ 思い出 (MEMORIES) ─▶ 仲間 (COMRADES) ─▶ LAST MESSAGE（クライマックス）
   場をあたためる        懐かしむ             仲間を振り返る         感謝とメッセージ
```

- 1章あたりのお題数 = `卒業生の人数`（最小4・最大10）。卒業生を順番に回すと、全員に各章が1回ずつ回る計算。
- 仲間の章を規定数こなすと、NEXT の上に「LAST MESSAGE ›」が現れ、司会者をクライマックスへ誘導。
- LAST MESSAGE のお題は通常出題では使わず、クライマックス用に温存。
- 司会者がカテゴリーを指定すると、その章に固定（「自動」で流れに復帰）。

### 出題ロジック

- 一度出たお題はゲーム中は除外。
- あるカテゴリーを使い切っても、すぐにはリセットせず**他カテゴリーの未使用お題を優先**。全て使い切った場合のみリセット。
- リセット直後も、最近出たお題（カテゴリーの半数ぶん）は除外して短時間の再登場を防ぐ。
- 特別カードは低確率（通常10%／盛り上がり16%／しっとり8%）。2枚連続では出ない。各卒業生の最初の1枚目にも出ない。
- 盛り上がりモード：`hype` タグ（暴露・指名系）の重みを3倍、他章でも40%で笑い系を混ぜる、指名系特別カードが出やすい。
- しっとりモード：`calm` タグ（感謝・思い出系）の重みを3倍、笑いの章でも50%で思い出系を出す、写真・全員カードが出やすい。

## 3. ユーザーフロー

```
[トップ] ──START──▶ (卒業生0人) ─▶ [設定: 卒業生登録] ──この卒業生で START──┐
   │                                                                  │
   └───────────▶ [卒業生選択] ◀── 名前タップ / 司会メニュー「卒業生を変える」 ◀─┘
                      │
                      ▼
                  [準備] ──お題を引く──▶ [お題] ──NEXT──▶ [お題] ──NEXT──▶ …
                                          │  ▲
                                          │  └── ← 戻る（1枚前に戻る／NEXTで再表示）
                                          │
                          (仲間カテゴリー) └─「その人を指名する」─▶ [指名された方から、◯◯さんへ一言。]
                                          │
                       (流れが仲間まで到達) └─「LAST MESSAGE ›」/ 司会メニュー
                                                     ▼
                                 [LAST MESSAGE 導入] ──MESSAGE──▶ [最後のお題]
                                         ▲                          │
                                         └──── 次の卒業生へ ◀───────┤
                                                                    ▼ (全員終了 / フィナーレへ)
                                                              [フィナーレ ＋ 紙吹雪]
```

誤操作対策

- すべての画面に「戻る」（会場モードでは司会メニューとキーボードから）。
- お題画面の戻る/NEXT は履歴ベース。戻ってから NEXT を押すと**同じお題を再表示**（新しく引かない）。
- 「最初に戻る」「最初から始める」「削除」は確認ダイアログ付き。
- 進行状況も LocalStorage に保存。うっかり再読み込みしても同じ画面・同じお題から再開。

## 5. データ構造

```ts
type Category = "laugh" | "memory" | "friends" | "last";

interface Topic    { id: string; category: Category; text: string; tags: ("hype" | "calm")[]; builtIn: boolean }
interface Graduate { id: string; name: string; nickname: string }
interface Settings { venueMode: boolean; mood: "normal" | "hype" | "calm" }

type Card =
  | { kind: "topic"; topicId: string; category: Category; text: string }
  | { kind: "special"; special: "nominate" | "reverse" | "everyone" | "photo" }
  | { kind: "reply" };                       // 仲間カテゴリーの「その人を指名する」

interface GameState {
  screen: Screen;
  graduateId: string | null;
  chapter: Category; chapterCount: number; chapterLocked: boolean;   // 流れ
  usedTopicIds: string[];                                            // 出たお題
  history: { graduateId: string; card: Card }[]; cursor: number;     // 戻る/進む
  lastDone: string[]; lastCard: {...} | null; lastRevealed: boolean; // LAST MESSAGE
  returnTo?: Screen;
}
```

LocalStorage キー

| キー | 内容 |
| --- | --- |
| `lasttalk:v1:graduates` | 卒業生（最大10名） |
| `lasttalk:v1:topics` | お題（標準＋カスタム。編集・削除も反映） |
| `lasttalk:v1:settings` | 会場モード・出題モード |
| `lasttalk:v1:game` | 進行状況（再読み込みしても再開できる） |

## 6. お題一覧

🔥 = 盛り上がりモードで優先（hype）／🕯 = しっとりモードで優先（calm）

### 1. 笑い（LAUGHTER）— 序盤
1. JCで一番飲んだ夜。どこで、誰と、何が起きた？ 🔥
2. 酔って一番やらかした話を、今夜で時効にしてください。 🔥
3. 記憶をなくした翌朝、知って一番ヤバかった事実は？ 🔥
4. JCで一番お酒が強い人は？伝説のエピソードとともに。 🔥
5. 飲みの席のノリで決まって、本当にやった一番無茶なことは？ 🔥

7. 家族に一番怒られたJCの日。いったい何をした？ 🔥
8. 京都会議や全国大会、夜の部で起きた一番の事件は？ 🔥
9. 理事会や例会で、一番笑いをこらえた瞬間は？ 🔥
10. 議案書や事業計画で、一番ヒヤッとしたミスの話。 🔥
11. 先輩に言われて「は？」と思った一言と、そのときの状況は？ 🔥
12. この中で一番クセが強い人の、一番クセが強いエピソードは？ 🔥
13. 委員長時代、一番キレそうになった出来事は？ 🔥

| --- | --- | --- |

## 7. UIデザイン方針

- **配色**：ダークネイビー（#0c1120）→ ほぼ黒（#07090f）のグラデーション × アイボリー（#f4efe6）× シャンパンゴールド（#c9a96e）。LAST MESSAGE 以降は背景をさらに暗転。
- **書体**：欧文は Cormorant Garamond（細身のセリフ、広い字間）、和文は Shippori Mincho（太めの明朝）。ホテルの式次第のような品のある組み合わせ。フォントはビルド時に同梱され、当日オフラインでも表示が崩れない。
- **お題の大きさ**：`min(6.4vw, 10.5vh)`（会場モードは `min(8vw, 13.5vh)`）。1920×1080 のプロジェクターで1文字約110〜145px。5〜10m先からでも読める。
- **装飾**：細いゴールドのヘアライン、字間の広い小さな英字ラベル、周辺減光のみ。アイコンや絵文字は使わない。
- **ボタン**：枠線だけの細いゴールドボタン。主ボタンは常に1つ・画面下中央。タップ領域は最小44px以上。
- **アニメーション**：フェード・文字の軽いスライド・お題切り替え・LAST MESSAGE の段階的な表示・フィナーレの紙吹雪のみ。opacity / transform だけを動かし 60fps を維持。`prefers-reduced-motion` で停止。
- **司会メニュー**：右下に薄く表示（参加者からはほぼ見えない）。開くと下からシート（PCでは中央パネル）。
- **会場モード**：お題をさらに拡大、戻るボタン・補足文・進行インジケーターを隠し NEXT のみを残す。
- **キーボード / リモコン**：→ / Space / PageDown で進む、← / PageUp で戻る、S スキップ、F 全画面、V 会場モード、H / Esc 司会メニュー。プレゼン用リモコンでそのまま操作できる。

## 8. 参加者も楽しむ仕組み（追加）

| 機能 | 内容 |
| --- | --- |
| シャッフル演出 | お題を引くと、ダミーのお題が高速で流れて減速し、本命で止まる（約3.4秒）。参加者のスマホでも同時に流れる。戻る・再読み込み・途中参加では再生しない。設定でオフにできる |
| 卒業生ルーレット | 卒業生選択画面の「ランダムで選ぶ」。光が名前を巡って止まり、選ばれた人の画面へ進む。まだ話していない人ほど当たりやすい。参加者のスマホでも同じルーレットが回る |
| リアクション | 参加者のスマホ下部に 👏拍手・😂爆笑・😭泣ける・🔥アツい。押すと自分の画面に浮かび、司会者（スクリーン）の画面の左右の端と、他の参加者の画面にも浮かぶ。1.5秒ごとにまとめて送信し、混雑時は自動で休む |
| 同時表示（ログイン不要） | 司会者が「参加者用QR」から同時表示をオンにすると、QR/リンクを開いた参加者の画面が司会者と連動。ntfy.sh 経由、司会者の端末の鍵で署名し、偽のメッセージは無視 |

通信が不安定なとき：送信失敗は自動で再送。つなぎっぱなしの接続が使えない回線では、参加者側が数秒おきに取りに行く方式（お題・リアクションとも）へ自動で切り替わる。
| 優勝発表 | 卒業生が話している間（お題・LAST MESSAGE）に届いたリアクションを、その卒業生のポイントとして数える。全員の LAST MESSAGE が終わると「本日の優勝は…」→「結果発表」で下位から順にバー（数に比例）が伸び、最後に優勝者を発表。同点は同時優勝。フィナーレにも優勝者を表示。司会メニューの「優勝発表へ」でいつでも出せる |

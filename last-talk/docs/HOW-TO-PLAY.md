# LAST TALK 説明文

## 1. LINE で事前に送る案内（参加用リンクと一緒に）

> アプリの「参加者用QR」→「LINEで送る」を押すと、短い案内＋リンクが自動で入ります。もっと詳しく伝えたいときは、下の文章を先に送ってください。

```
【卒業生を送る会：LAST TALK のご案内】

当日は「LAST TALK」というトークゲームで、卒業生を送り出します。

■ どんなゲーム？
卒業生3名に、スマホに出るお題で思い出話をしてもらいます（スクリーンなし。全員のスマホに同じお題が出ます）。
お題は「笑い → 思い出 → 仲間 → 最後のメッセージ」の順に進みます。
1問ごとに話す人が交代。現役のみなさんに振られるお題もあります。

■ みなさんにしてほしいこと
1. 当日、下のリンクをスマホで開く（アプリ・ログイン不要）
2. 名前を入れて「参加する」（現役ルーレットで指名されるかも）
3. 話が良かったら 👏😂😭🔥 をどんどん押す
4. 「✍ 寄せ書きを書く」から、卒業生へ一言（最後のメッセージの前に、みんなのスマホに流れます）

■ 卒業生も飲みます（ソフトドリンクOK）
・話へのリアクションが少なかったら → その卒業生が一杯
・「ホント？盛ってる？」投票で「盛ってる」が多かったら → 一杯
・モノマネのあと10秒の判定タイムで、リアクションが足りなければ → 一杯

■ 最後に優勝発表！
リアクションは、そのとき話している卒業生のポイントになります。
いちばんリアクションを集めた卒業生が「本日の優勝」です。

（参加用リンク）
```

## 2. 司会の開始トーク（そのまま読める台本）

```
ここからは「LAST TALK」の時間です。

今日の主役、卒業生の3名には、このあとスマホに出るお題で
思い出話をしていただきます。皆さんのスマホにも、同じお題が出ます。
お題は、最初は笑える話から。だんだん思い出、仲間の話になって、
最後は卒業生から皆さんへのメッセージで締めくくります。

1問ごとに話す人が交代します。
ときどき「現役のみんなに聞きます」というお題も出ますので、
現役の皆さんも油断しないでください。

話が良かったら、画面の下の 👏 😂 😭 🔥 を押してください。
押したリアクションは、そのとき話している卒業生のポイントになって、
最後に「本日の優勝」を発表します。

そして卒業生の皆さん。話へのリアクションが少なかったら、一杯です。
「ホント？盛ってる？」投票で「盛ってる」が多くても、一杯。
飲み物はソフトドリンクでも大丈夫です。

まだ開いていない方は、LINE のリンクからどうぞ。
名前を入れておくと、現役ルーレットで指名されるかもしれません。
それから、画面左上の「寄せ書きを書く」から、卒業生に一言どうぞ。
最後のメッセージの前に、皆さんのスマホに流します。

それでは、最初の卒業生から。お題、引きます！
```

```
卒業生がお題に答えるトークゲーム。
リアクションが少ないと卒業生が一杯、最後はリアクション数で優勝発表！
```

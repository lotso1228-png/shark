# LAST TALK 説明文

## 1. LINE で事前に送る案内

アプリの「参加者用QR」→「LINEで送る」でも、短い案内とリンクが送れます。
くわしく伝えたいときは、先にこの文章を送ってください。

```
【LAST TALK のご案内】
卒業生を送る会で、スマホを使ったトークゲームをします。

◆ どんなゲーム？
・卒業生3人が、スマホに出るお題で思い出話をします
・お題は「笑い → 思い出 → 仲間 → 最後のメッセージ」の順
・みなさんのスマホにも、同じお題が出ます

◆ 当日やること
① リンクを開いて、名前を入れる
② 話が良かったら 👏😂😭🔥 を押す
③「寄せ書き」で、卒業生に一言送る

◆ ルール
・リアクションが少ない話は、卒業生が一杯
・「盛ってる」と思われた話も、一杯
・リアクションを一番集めた卒業生が優勝！
※飲み物はソフトドリンクでもOKです

アプリもログインも不要です。
（参加用リンク）
```

## 2. 司会の開始トーク（そのまま読める台本）

```
ここからは「LAST TALK」の時間です。

卒業生の3人に、スマホに出るお題で思い出話をしてもらいます。
みなさんのスマホにも、同じお題が出ます。

お題は、笑える話から始まって、思い出、仲間の話へ。
最後は、卒業生からのメッセージで締めくくります。
1問ごとに、話す人が交代します。

みなさんに、お願いが3つあります。

1つめ。話が良かったら、画面の下の 👏😂😭🔥 を押してください。
押した数が、話している卒業生のポイントになります。
最後に、優勝を発表します。

2つめ。卒業生のお題2問ごとに、現役が答える「現役トーク」が入ります。
ルーレットで指名されたら、よろしくお願いします。

3つめ。画面の左上「寄せ書きを書く」から、卒業生に一言どうぞ。
最後のメッセージの前に、みんなで読みます。

そして、卒業生のみなさん。
リアクションが少なかった話は、一杯飲んでいただきます。
「ホント？盛ってる？」の投票で、「盛ってる」が多くても一杯です。
ソフトドリンクでも大丈夫です。

まだ開いていない方は、LINE のリンクからどうぞ。
それでは、お題を引きます！
```

```
卒業生がお題に答えるトークゲームです。
ウケなかった話は卒業生が一杯。最後はリアクションの数で優勝発表！
```
